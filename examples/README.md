# Data Analysis Examples

This directory contains practical examples demonstrating data analysis workflows and techniques.

## Available Examples

### 1. Complete Workflow (`complete_workflow.py`)
A comprehensive end-to-end example covering:
- Data generation and loading
- Data cleaning and preprocessing
- Exploratory data analysis (EDA)
- Feature engineering
- Model training (Random Forest)
- Model evaluation and visualization
- Results interpretation

**Run:**
```bash
python complete_workflow.py
```

**Outputs:**
- `eda_visualizations.png` - EDA plots
- `model_evaluation.png` - Model performance metrics

### 2. Quick Start (`quick_start.py`)
A simple introduction showing:
- Basic pandas operations
- Simple visualizations
- Quick data exploration

**Run:**
```bash
python quick_start.py
```

## Requirements

Install required packages:
```bash
pip install pandas numpy matplotlib seaborn scikit-learn scipy
```

## Usage Tips

1. **Modify for your data**: Replace sample data generation with your own data loading
2. **Customize parameters**: Adjust model parameters, visualization styles, etc.
3. **Extend examples**: Add your own analysis steps and visualizations
4. **Learn by doing**: Experiment with different approaches and techniques

## Learning Path

1. Start with `quick_start.py` for basic operations
2. Move to `complete_workflow.py` for comprehensive workflow
3. Apply techniques from cheat sheets in parent directory
4. Create your own analysis scripts
